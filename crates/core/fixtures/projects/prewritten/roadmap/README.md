# prewritten — Roadmap

A synthetic project that pre-writes every brief: the house header with bare hashes, a `◐` row, a
wrapped header line in each brief, a pickup gate on the next brief, a pickup note, a charter, and a
decision log nested in the package folder with an index table. Nothing is in progress: an open brief
without a completion note means nothing here.
